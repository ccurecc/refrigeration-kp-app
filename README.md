# FrozenWest КП

Десктопное приложение для расчёта холодильных камер из сэндвич-панелей и подготовки коммерческих предложений (КП) в PDF.

## Стек

- Electron + React + TypeScript
- Vite / electron-vite
- pnpm

## Команды

```bash
pnpm install        # установка зависимостей
pnpm dev            # запуск в режиме разработки
pnpm typecheck      # проверка типов (tsc --noEmit)
pnpm build          # типы + сборка renderer/main/preload в out/
pnpm dist:win       # сборка Windows-установщика (.exe, NSIS) в release/
pnpm dist:mac       # сборка macOS .dmg в release/
```

Финальная Windows-сборка проверяется на Windows 10.

## Что считает программа

Рабочая ширина панели — **1190 мм** (номинал 1200, замок съедает 10 мм). Профили продаются палками по 2 м с округлением вверх, панели — целыми штуками.

- **Стены:** длинные стены идут полным наружным размером, торцевые стены стоят внутри между длинными; панель `1190 × (высота − толщина)`. Кол-во = `2·⌈длина/1190⌉ + 2·⌈(ширина − 2·толщина)/1190⌉`.
- **Потолок:** панель `1190 × узкая_сторона`, число полос = `⌈длинная/1190⌉` (потолки всегда по узкой стороне).
- **Пол:** лежит между стенами, поэтому панель `1190 × (узкая − 2·толщина)`, число полос = `⌈(длинная − 2·толщина)/1190⌉`.
- **Внутренний угол 40×40:** `2·периметр + 4·высота`.
- **Швеллер пола (толщина+3 мм):** периметр; **швеллер проёма:** `2·(ширина_двери + высота_двери)`.
- **Наружный вертикальный угол (40+т)×(40+т):** `4·высота`; **наружный потолочный 40×(40+т):** периметр.
- **Расходники** (пена/герметик/саморезы) — по норме на м² фактической площади.

Монтажная схема: швеллер крепится к полу помещения, стены вставляются в швеллер и стоят на полу помещения, потолок лежит сверху на стенах. Если камера с полом, половая панель укладывается после стен внутрь чистого проёма между стенами. На виде сверху показано, что длинные стены перекрывают торцевые, а торцевые стоят внутри между ними.

## Оптимизация габаритов

Программа предлагает варианты «в меньшую» и «в большую» сторону только по стенам: длинные стены по полному пролёту `длинная`, торцевые стены по внутреннему пролёту `короткая − 2·толщина`. Пол и потолок в оптимизации размеров не учитываются. Если подрезка есть по обеим осям стен, кнопка меняет обе стороны сразу, чтобы после применения стены стали без подрезки.

## Возможности

Несколько камер в одном КП, подробный и краткий режим КП, переключатель НДС, толщины 50/60/80/100/120, наполнитель PIR/PUR/ППС/свой, произвольная дверь (название, проём, порог, цена, монтаж), опциональный блок оборудования с фото, ручные доп. строки сметы (доставка/разгрузка/спецтехника), справочник цен и норм с автосохранением, сохранение/открытие расчёта в JSON, экспорт PDF, отдельная печать PDF с визуализациями для продавца, 3D-вид с полным потолком и размерными линиями, вид сверху с раскладкой панелей и подсветкой подрезки. В PDF выводится PNG-снимок реальной Three.js 3D-модели с размерами, а не упрощенный вид сверху.

## Иконка приложения

Заготовка логотипа — `build/icon.svg`. Чтобы зашить иконку в установщик, сконвертируйте её в `build/icon.ico` (256×256, например через `npx electron-icon-builder` или онлайн-конвертер) и добавьте в `package.json` → `build.win`: `"icon": "build/icon.ico"`. Без этого установщик собирается со стандартной иконкой Electron.
